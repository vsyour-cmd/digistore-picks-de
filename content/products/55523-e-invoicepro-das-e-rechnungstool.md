<h3>1. Software-Voraussetzungen</h3>
<ul>
<li>
<p><strong>Betriebssystem:</strong> Windows 10 oder Windows 11 (64-Bit empfohlen).</p>
</li>
<li>
<p><strong>Microsoft Excel:</strong> Eine Version, die Makros unterstützt (Excel 2016, 2019, 2021 oder Microsoft 365). Die Desktop-App ist zwingend erforderlich (Excel Online funktioniert nicht).</p>
</li>
<li>
<p><strong>Java Runtime Environment (JRE):</strong> * <strong>Version:</strong> Java 17 (LTS) oder höher.</p>
<ul>
<li>
<p><strong>Warum:</strong> Java wird vom "Mustang-CLI" benötigt, um die unsichtbare XML-Datei in die PDF einzubetten.</p>
</li>
<li>
<p><strong>Download-Tipp:</strong> OpenJDK (z. B. von <em>Adoptium/Temurin</em>) ist kostenlos und ideal.</p>
</li>
</ul>
</li>
</ul>
<h3>2. Einstellungen in Excel</h3>
<ul>
<li>
<p><strong>Makros aktivieren:</strong> Beim Öffnen der Datei muss die gelbe Statusleiste mit „Inhalt aktivieren“ bestätigt werden.</p>
</li>
<li>
<p><strong>Dateiformat:</strong> Die Datei muss immer als <strong>.xlsm</strong> (Arbeitsmappe mit Makros) oder <strong>.xltm</strong> (Vorlage mit Makros) gespeichert bleiben.</p>
</li>
<li>
<p><strong>Zugriffsrechte:</strong> Das Programm benötigt Schreibrechte in dem Ordner, in dem die PDFs gespeichert werden sollen (Vorsicht bei restriktiven Cloud-Ordnern ohne Offline-Verfügbarkeit).</p>
</li>
</ul>
<h3>3. Mitgelieferte Komponenten</h3>
<p>Damit der Export funktioniert, müssen im selben Ordner wie die Excel-Datei (oder im im Code definierten Pfad) folgende Dateien liegen:</p>
<ul>
<li>
<p><strong>Mustang-CLI-2.21.0.jar</strong> (Die "Maschine", die die E-Rechnung baut).</p>
</li>
<li>
<p><strong>Logos/Bilder:</strong> Falls das Makro externe Bilddateien für den Briefkopf nachlädt.</p>

</ul>
